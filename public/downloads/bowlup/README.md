## Short case-study copy you can adapt

**Overview.** Bowlup is a recipe companion that helps people find a meal, keep inspiration close, and follow clear cooking steps.

**Design focus.** Create an inviting first impression while giving visitors a direct route to a recipe. The interface uses Bowlup's approved warm palette and typography, food-led photography, generous spacing, and a full-height Find–Save–Cook preview.

**Interaction and responsiveness.** Timed hero photographs introduce variety. Native scroll connects the sections through gradual brand-color changes. The story adapts from a desktop split to a phone composition, with reduced-motion alternatives.

**What shipped.** A published responsive website with public recipe browsing, search filters, recipe details, and an interactive local preview of saving and cooking.

These are actual production-browser screenshots. The browser clock was controlled to capture settled animation and consistent recipe content. No page text, colors or layout were changed for capture.
