# Bowlup project guidance

For frontend design work, read and use the requested project skills:

- Impeccable: `.agents/skills/impeccable/SKILL.md`
- Taste: `.agents/skills/design-taste-frontend/SKILL.md`

Preserve the established product context in PRODUCT.md, design decisions in DESIGN.md, and approved brand assets in public/brand. User instructions take precedence over skill defaults. Skills and tools must not be treated as permission to replace the approved Bowlup direction during a refinement.

Skill source versions and readiness notes are in `.agents/skills/SOURCES.md`.
